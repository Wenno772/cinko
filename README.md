# CINKO

App de foot à 5 : cartes joueurs qui évoluent, notes après match, classements d'équipes et de joueurs.

- `web/` : l'app (site statique sans étape de build, JS + Supabase). C'est ce que Vercel publie.
- `web/demo/` : prototype cliquable avec données fictives.
- `prototype/` : copie d'origine du prototype.
- `supabase/schema.sql et supabase/migration-2.sql` : tables et règles de sécurité de la base.
